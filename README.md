## 🚀 Cara Menjalankan Program

**1. Clone repository**

```bash
git clone https://github.com/USERNAME/NAMA-REPO.git
cd NAMA-REPO
```

**2. Masuk ke folder tugas**

```bash
cd Tugas01
```

**3. Compile program**

```bash
javac NamaFile.java
```

**4. Jalankan program**

```bash
java NamaFile
```
